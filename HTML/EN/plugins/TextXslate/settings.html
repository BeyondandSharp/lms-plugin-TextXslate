Text::Xslate function table

Perl function table used by Text::Xslate templates. This file is an ordinary Perl module: write the subs, then list them in build(). The functions have no prefix (for example number(), pad(), prefix()); names that would be ambiguous next to a Perl built-in are spelled out (hexadecimal, character, subtract). The helpers _text(), _integer() and _truthy() normalise arguments. The file is loaded once, so changes take effect after restarting LMS.
